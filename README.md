# Getting Started

## Requirements

- Python 3.7+
- [Flask](https://flask.palletsprojects.com/)
- Flask-CORS
- A web browser with GPS permission enabled
- Internet connection (required for map tiles and routing)

## Installation

1. Install dependencies:
   ```
   pip install flask flask-cors
   ```

## Running the Project

1. Open a terminal window.
2. Start the backend server:
   ```
   python app.py
   ```
3. Open `index.html` directly in your web browser (e.g., double-click the file).
